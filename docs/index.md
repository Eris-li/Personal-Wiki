# Personal Wiki

这里收集为开发、科研与持续学习提供背景的知识材料。内容既可以是保留论文、教材或课程上下文的长篇笔记，也可以是跨来源概念页和领域知识地图。

## 开始浏览

- [Personal Wiki 架构地图](maps/meta/index.md)：了解来源笔记、概念页和知识地图如何配合。
- [知识对象](concepts/meta/knowledge-object/index.md)：了解本仓库的内容组织边界。
- [交叉链接](concepts/meta/cross-link/index.md)：了解完整对象与长笔记章节如何形成知识网络。
- [标签索引](tags.md)：按跨领域标签发现相关内容。

## 使用提示

目录只表达内容类型和粗粒度领域归属。真正的概念前置、对比、来源和延伸关系由正文链接表达；长笔记中的稳定章节锚点也可以成为跳转目标。
