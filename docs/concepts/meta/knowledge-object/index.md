# 知识对象

知识对象是本知识库中可独立维护、引用和迁移的内容单元。它可以是一篇按来源组织的长篇笔记、一个跨来源概念页，或一张领域知识地图；文件不再被强制等同于原子化词条。

## 三种对象

- **来源笔记**保留论文、教材或课程原有的叙事、推导与上下文；
- **概念页**综合多个来源对同一概念的定义、性质和应用；
- **知识地图**组织领域边界、先修关系和推荐阅读路径。

每个知识对象独占一个文件夹，入口是 `index.md`，专用图片、Notebook 和补充资料与其共置。长篇来源笔记中的章节可以借助[交叉链接](../cross-link/index.md)成为细粒度知识节点，而不必为了链接能力机械拆分文件。

## 何时建立概念页

当一个概念被多个来源引用、需要比较不同定义，或需要一个长期稳定的综合入口时，才值得建立独立概念页。只出现在单份材料中的例子或局部推导应先留在来源笔记中。
