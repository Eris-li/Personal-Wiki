# Personal Wiki 架构地图

这张地图说明知识库三层内容之间的关系，并作为当前示例导航。

## 内容流向

1. 首先按论文、教材或课程编写完整的来源笔记，保留原始论证上下文。
2. 使用稳定章节锚点，让长笔记中的重要知识可以被精确引用。
3. 当同一概念出现在多个来源中时，创建概念页进行比较和综合。
4. 使用知识地图组织一个领域的先修关系、关键概念和推荐阅读路径。

## 架构概念

- [知识对象](../../concepts/meta/knowledge-object/index.md)：来源笔记、概念页与知识地图的共同边界。
- [交叉链接](../../concepts/meta/cross-link/index.md)：连接完整对象和长笔记内部章节。
